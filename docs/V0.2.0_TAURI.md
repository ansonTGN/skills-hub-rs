# Skills Hub Rust v0.2.0-alpha.1 — Desktop Tauri

Esta iteración añade una interfaz de escritorio Tauri 2 sobre el mismo motor Rust de `skills-hub-rs`.

## Alcance de alpha.1

La GUI expone operaciones reales del motor, no datos simulados:

- dashboard con Skills, targets y tools detectados;
- biblioteca de Skills con estado, tags y targets;
- enable/disable;
- update individual y global;
- instalación desde directorio local;
- instalación desde Git, con branch/tag y subdirectorio;
- sincronización global o por proyecto;
- modos auto, symlink, junction y copy;
- unsync;
- búsqueda en `skills.sh` e instalación desde un resultado;
- scan de Skills presentes en herramientas instaladas;
- custom tools;
- papelera de 30 días, restore y purge.

## Arquitectura

```text
Desktop WebView (HTML/CSS/JS)
          │
          │ Tauri IPC invoke
          ▼
skills-hub-rs-desktop
          │
          │ path dependency
          ▼
skills-hub-rs core
  ├─ manager.rs
  ├─ store.rs / SQLite
  ├─ fsops.rs
  ├─ tools.rs (47 adapters)
  └─ online.rs / skills.sh
```

No se duplica la lógica de filesystem ni persistencia en JavaScript. La UI llama a comandos Tauri que delegan en `SkillsHub`.

sudo apt update

  libssl-dev \
  libgtk-3-dev \
  libwebkit2gtk-4.1-dev \
  librsvg2-dev \

El proyecto usa Rust 1.96.0.

## Generar lockfile del desktop

Desde la raíz:

```bash
cargo generate-lockfile --manifest-path desktop/src-tauri/Cargo.toml
```

Debe generarse:

```text
desktop/src-tauri/Cargo.lock
```

Se recomienda versionarlo antes de abrir el PR.

## Ejecutar la GUI

Desde la raíz:

```bash
cargo run --manifest-path desktop/src-tauri/Cargo.toml
```

La aplicación utiliza por defecto la misma biblioteca que la CLI:

```text
~/.skillshub-rs
```

Para una prueba aislada:

```bash
export SKILLS_HUB_HOME=/tmp/skills-hub-rs-gui-test
cargo run --manifest-path desktop/src-tauri/Cargo.toml
```

## Validación

```bash
./scripts/validate-desktop-linux.sh
```

Ese script valida formato, lockfile, `cargo check`, Clippy y build de la aplicación Tauri.
